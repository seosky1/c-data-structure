# C Data Structures

This repository contains data structures implemented in C.

I started this project to become more comfortable with C before taking a systems programming course. Along with learning how each data structure works, I am practicing pointers, structs, dynamic memory allocation (`malloc`), memory deallocation (`free`), and separating code into header and source files.

## Implemented

* Vector
* Stack
* Queue
* Singly Linked List
* Hash Table
* Binary Search Tree

Each data structure includes basic operations such as insertion, deletion, lookup, and printing.
